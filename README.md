### Currently

Building **[MantleUI](https://github.com/Ako2003/mantleui)** — an open-source React component library I started to go deep on architecture, testing, and accessibility patterns. 109 components, 676+ tests, CI/CD pipeline, published on npm as [`@mantleui/react`](https://www.npmjs.com/package/@mantleui/react). Live docs at [mantleui.vercel.app](https://mantleui.vercel.app).

It started as a learning exercise and turned into something I actually use. Everything is built around compound components, polymorphic types, controlled/uncontrolled patterns via a custom `useControllable` hook, headless hooks for tables and popovers, and a color system that supports both presets and custom hex. The whole thing is published, tree-shakeable, accessible, and test-covered — because the point was to practice doing things properly, not just shipping.
